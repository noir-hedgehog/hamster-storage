# 家庭收纳管理系统

一个现代化的家庭收纳工具，像维护文件系统一样管理你的家庭物品。

## 功能特性

### 🏠 多层储物空间管理
- **地点** → **房间** → **收纳位置** 三层树状结构
- 支持多个地点（如：主住所、仓库、办公室）
- 每个地点下可创建多个房间
- 每个房间可创建多个收纳位置（如：衣柜、抽屉、书架）

### 📦 物品管理
- **基本信息**：名称、描述、品牌、分类
- **位置管理**：自动关联到收纳位置
- **数量管理**：支持数量和单位设置
- **价格与折旧**：
  - 记录购买价格和购买日期
  - 支持年折旧率设置
  - 自动计算当前价值（考虑折旧）
- **过期管理**：设置过期日期，自动提醒
- **库存阈值**：设置最小/最大库存阈值，自动提醒补货或库存过多
- **标签系统**：支持多标签分类和筛选
- **自定义属性**：灵活添加自定义属性
- **RFID/条码**：支持RFID和条形码录入
- **图片管理**：支持上传多张物品图片
- **颜色标记**：为物品设置颜色标识

### 📊 数据统计与分析
- **仪表板**：总览所有统计数据
- **价值统计**：总价值、当前价值、折旧统计
- **分类分析**：柱状图展示分类分布
- **过期状态**：饼图展示过期状态分布
- **位置价值**：横向柱状图展示各位置价值分布
- **最近添加**：显示最近添加的物品

### 🔔 智能提醒系统
- **过期提醒**：即将过期（7天内）和已过期物品提醒
- **库存不足**：低于最小阈值时提醒
- **库存过多**：超过最大阈值时提醒
- **严重程度分级**：高、中、低三级提醒

### 🏷️ 标签打印
- 支持批量选择物品打印标签
- 多种标签尺寸（小、中、大）
- 显示物品名称、位置、数量、RFID等信息
- 打印预览功能

### 📡 RFID 扫描
- RFID标签扫描和识别
- 批量生成RFID标签
- 扫描历史记录

### 🎯 场景化收纳模式
- **购物入库**：整理刚购买的物品
- **搬家整理**：系统化整理物品准备搬家
- **旅行打包**：准备旅行物品并记录
- **定期整理**：定期检查和整理储物空间
- 每个场景都有详细的步骤指导

### 🔄 数字孪生视图
- 可视化查看所有储物空间和物品分布
- 四级联动浏览：地点 → 房间 → 收纳位置 → 物品
- 实时统计各层级的数据

### 💾 数据管理
- **导出功能**：
  - JSON格式：完整数据备份
  - CSV格式：Excel兼容，方便编辑
- **导入功能**：从JSON文件导入数据
- 数据统计显示

### ✨ 批量操作
- 批量选择物品
- 批量删除物品
- 批量打印标签

### 📱 响应式设计
- 完美适配桌面、平板、手机
- 移动端优化的交互体验

## 技术栈

- **前端框架**：React 18 + TypeScript
- **构建工具**：Vite
- **UI组件**：Radix UI + Tailwind CSS
- **图表库**：Recharts
- **图标**：Lucide React
- **数据存储**：LocalStorage（本地存储）

## 安装与运行

### 前置要求
- Node.js 18+ 
- npm 或 yarn

### 安装依赖
```bash
cd Frontend
npm install
```

### 开发模式
```bash
npm run dev
```
应用将在 http://localhost:3000 启动

### 构建生产版本
```bash
npm run build
```

## 使用指南

### 1. 创建储物空间结构
1. 点击左侧边栏的 **+** 按钮创建地点
2. 点击地点旁的 **+** 按钮创建房间
3. 点击房间旁的 **+** 按钮创建收纳位置

### 2. 添加物品
1. 点击 **物品管理** 标签页
2. 点击 **添加物品** 按钮
3. 填写物品信息：
   - 基本信息（名称、描述、品牌、分类）
   - 选择收纳位置
   - 设置数量和单位
   - 设置价格和折旧率（可选）
   - 设置过期日期（可选）
   - 设置库存阈值（可选）
   - 添加标签和自定义属性
   - 上传图片（可选）
   - 设置颜色（可选）

### 3. 查看统计
- 在 **仪表板** 查看总体统计
- 查看各类图表分析

### 4. 管理提醒
- 在 **提醒中心** 查看所有提醒
- 按严重程度排序

### 5. 打印标签
1. 点击顶部工具栏的 **打印** 按钮
2. 选择要打印的物品
3. 选择标签尺寸
4. 点击打印

### 6. RFID管理
1. 点击顶部工具栏的 **RFID** 按钮
2. 扫描或输入RFID标签
3. 批量生成RFID标签

### 7. 场景模式
1. 点击顶部工具栏的 **场景模式** 按钮
2. 选择场景（购物入库、搬家整理等）
3. 按照步骤完成整理

### 8. 数据备份
1. 点击顶部工具栏的 **数据** 按钮
2. 导出JSON或CSV格式
3. 需要时导入备份数据

## 数据存储

所有数据存储在浏览器的 LocalStorage 中，包括：
- `locations`：地点数据
- `rooms`：房间数据
- `storages`：收纳位置数据
- `items`：物品数据

## 注意事项

1. **数据备份**：定期使用导出功能备份数据，避免数据丢失
2. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Safari、Edge）
3. **存储限制**：LocalStorage 有大小限制（通常5-10MB），如果数据量很大，建议定期清理
